## Description

This website is a simplified Fiverr, a user can register and log in to the system to publish/share job notices, as well as find suitable jobs that other users have posted.
All available job notices sent by other users can be viewed at main page. All notice posts have publishers contact information. Using this contact information (email) users can negotiate and get more detailed information from the publisher privately. We try to add react.

## How to Run?
To run this project you do not need any external downloads, no external library was used. After downloading the whole project, simply double click on the **"mainpage.html"**, which will open the web application on your browser locally. From there you are free to navigate through inside the web application.

Note: This project uses localStorage in your browser to save/retrieve data. Make sure your browser version is at least following to be able to run this web application:
**Chrome 4.0+, Edge 8.0+, Firefox 3.5+, Safari 4.0+, Opera 11.0+**



## Usage

You are forced to register before being able to see any job notices published by all users. After making a valid account, you can use same information to log in. Once logged in you will be seeing all posts on the main page, each with their own *title*, *description*, *publisher*, and *contact information*. 

Navigating to profile and publish job notices options will become available after logged in. You will stay logged in until you press log out. In the profile one can see their own published posts, as well as their information that was asked on registration. All of the profile pictures are auto-mapped with users' country. There's also an *Edit / Remove Notice* option below user information, which lets users to change any of their account information, aside from their username, and remove any number of their published works at will.

Creating a notice page requires you to enter a *title* and a *description* for you to explain your need further. After clicking on finish, the notice will be published and can be viewed at either profile (when logged in), or main page.

Lastly, a user can log out using the button that appears after they log in.
